# Lifestyle Disease Prediction & Doctor Recommendation System

Final-year B.E. project (AI & Data Science, 2026). A Django web app that
predicts a user's risk of four lifestyle-related diseases from their daily
habits, explains the key influencing factors, and recommends suitable doctors.

Published: "Machine Learning-Based Disease Prediction Using Lifestyle and
Health Data", IJIRT, Vol. 12 Issue 11, April 2026.

## What it does
- Takes lifestyle inputs: diet, exercise, sleep, stress, smoking, alcohol,
  family history
- Predicts risk % for Diabetes, Hypertension, Heart Disease and Obesity
- Shows the top factors driving each prediction
- Recommends doctors based on the predicted condition

## Tech stack
Python, LightGBM, Scikit-learn, Pandas, Django, joblib, HTML/CSS/JS

## Model
- One LightGBM classifier per disease, each with its own feature set
- Stratified k-fold cross-validation; evaluated on accuracy, precision,
  recall, F1 and ROC-AUC (see `model_performance_report.csv`)
- Models saved with joblib and loaded by the Django app at runtime

## Limitations and next steps
- The dataset is synthetic (generated by `GenerateDataSet.py`), so results
  do not reflect real patients
- Current metrics are modest (best ROC-AUC 0.75); class imbalance is the
  main issue — threshold tuning and SMOTE are the planned next steps
- Evaluation and training scripts need to point to the same dataset version

## Run locally
1. `pip install django lightgbm scikit-learn pandas joblib`
2. `python manage.py migrate`
3. `python manage.py runserver`
4. Open http://127.0.0.1:8000
